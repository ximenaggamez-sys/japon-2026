# Japón 2026: guía de viaje

Sitio estático (HTML, CSS y JavaScript) que funciona sin conexión y se puede instalar en el teléfono.

## Publicarlo gratis con GitHub Pages

1. Crea una cuenta en https://github.com (o entra con la tuya).
2. Arriba a la derecha, haz clic en **+** → **New repository**.
   - Nombre: por ejemplo `japon-2026`
   - Visibilidad: **Public** (GitHub Pages gratis requiere repositorio público)
   - Haz clic en **Create repository**.
3. En la página del repositorio nuevo, haz clic en **uploading an existing file**.
4. Descomprime `japon-2026-web.zip` en tu computadora. Abre la carpeta y arrastra **todo su contenido** a la ventana de GitHub: `index.html`, `train.html`, `sw.js`, `manifest.webmanifest`, `.nojekyll` y las carpetas `data`, `icons`, `streets` y `vendor`.
   - En Mac, `.nojekyll` está oculto: en Finder pulsa Cmd + Shift + . (punto) para verlo.
   - Si el navegador no deja arrastrar carpetas, súbelas una por una desde **Add file → Upload files**.
5. Abajo, haz clic en **Commit changes**.
6. Ve a **Settings → Pages**. En **Build and deployment**, elige **Source: Deploy from a branch**, **Branch: main** y la carpeta **/ (root)**. Haz clic en **Save**.
7. Espera de 1 a 2 minutos y recarga la página. Arriba aparece tu dirección:
   `https://TU-USUARIO.github.io/japon-2026/`

## Instalarlo en el teléfono

- **iPhone (Safari):** abre la dirección → botón Compartir → **Agregar a inicio**.
- **Android (Chrome):** abre la dirección → menú ⋮ → **Instalar app** o **Agregar a la pantalla principal**.

Ábrelo una vez con internet para que se guarde todo; después funciona sin conexión.

## Actualizarlo

Sube los archivos nuevos con **Add file → Upload files** (reemplazan a los anteriores) y haz **Commit changes**. El sitio se actualiza solo en uno o dos minutos; en el teléfono, ciérralo y ábrelo de nuevo para ver la versión nueva.
